# Models

SQLAlchemy ORM models go here (one file per entity, e.g. `opportunity.py`,
`user.py`, `application.py`).

Not implemented yet — the opportunity schema needs to be finalized first
(see `docs/database/schema.md`, and the fields listed in the product
blueprint: source, source URL, title, category, organizer, description,
eligibility, location, mode, deadline, start date, verification status,
freshness timestamp, tags, skills, application URL).

Do not create models speculatively; add them alongside the service/route
that first needs them.
