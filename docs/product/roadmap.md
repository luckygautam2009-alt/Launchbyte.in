# Roadmap

This is a directional roadmap. For granular, current status, see
[`PROJECT_STATUS.md`](../../PROJECT_STATUS.md).

## Phase 0 — Foundation (current)

- Repository architecture and ownership model
- Frontend and backend scaffolds that boot cleanly
- Documentation and GitHub collaboration setup

## Phase 1 — Core Data & Auth

- Finalize opportunity schema
- Authentication (signup/login)
- First working ingestion → normalization pipeline for one opportunity
  category

## Phase 2 — Discovery MVP

- Opportunity list/search API and frontend UI
- Basic rule-based verification (required fields, source allowlist)
- Application tracker (manual entry)

## Phase 3 — Personalization

- User profile & preferences
- Recommendation matching + ranking
- Notifications for deadlines and new matches

## Phase 4 — Intelligence Layer

- AI-assisted verification signals (semantic duplicate detection, freshness)
- AI Copilot (opportunity guidance, application support)
- Team finder

## Beyond

Expand data sources, refine personalization, and iterate based on real
student usage.

> Sequencing may shift based on team capacity and what's learned along the
> way — this roadmap is a direction, not a contract.
