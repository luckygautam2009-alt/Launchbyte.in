# Documentation

Central documentation for LaunchByte, organized so any team member (or new
contributor) can understand the product and architecture without asking
around.

```text
docs/
├── product/           # Vision, features, roadmap
├── architecture/       # System, frontend, backend, AI architecture
├── api/                  # API reference (grows with backend/api/routes)
├── database/               # Schema documentation
└── contribution/             # Workflow, branching, coding standards
```

Start with [`product/vision.md`](./product/vision.md) if you're new to the
project, then [`architecture/system-architecture.md`](./architecture/system-architecture.md)
before touching code.
