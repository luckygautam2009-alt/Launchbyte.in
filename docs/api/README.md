# API Reference

This will document LaunchByte's REST API as routes are implemented.

## Current Endpoints

| Method | Path      | Description                     |
|--------|-----------|----------------------------------|
| GET    | `/`       | Service info / liveness          |
| GET    | `/health` | Health check (used by CI)         |

Interactive docs are also available at `http://localhost:8000/docs`
(Swagger UI, auto-generated by FastAPI) when running the backend locally.

## Planned Endpoints

Documented here as they're built — see `backend/api/routes/README.md` for
the list of planned route modules (auth, opportunities, users,
applications, recommendations).

## Conventions

- All endpoints are prefixed implicitly by the deployed base URL; no
  `/api/v1` prefix yet — add one before the first breaking change if
  versioning becomes necessary.
- Request/response shapes are defined in `backend/schemas/` — keep this
  doc's examples in sync when a schema changes.
