# Recommendation

Opportunity matching, ranking, and personalization logic.

- `matching/` — match opportunities to a user's profile/skills/interests.
- `ranking/` — order matched opportunities (recency, deadline urgency, fit score).
- `personalization/` — user-specific weighting/preferences layered on ranking.

Status: Planned. Depends on a finalized opportunity schema and real
opportunity data flowing through `data/opportunity-data/normalized/`.
