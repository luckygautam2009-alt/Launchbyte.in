# AI Verification

AI-assisted signals that support (not replace) the rule-based checks in
`data/verification/`.

- `source_check/` — assess source credibility/reputation.
- `duplicate_detection/` — semantic (not just exact-match) duplicate detection.
- `freshness/` — infer likely staleness from content signals (e.g. dates
  mentioned in the body vs. a stale posted date).

Status: Planned.
